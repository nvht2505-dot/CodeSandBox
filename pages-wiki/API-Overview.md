# Tổng quan API

(Nếu dự án có API / backend) mô tả ngắn các endpoint chính.

Ví dụ:
- GET /api/projects — danh sách project
- POST /api/projects — tạo project mới
- GET /api/projects/:id — chi tiết project
- POST /api/preview — trả về bản preview/sandbox

Auth
- JWT in Authorization header: `Authorization: Bearer <token>`
- OAuth flow: (nếu áp dụng)

Thêm phần chi tiết endpoint, request/response schema, mẫu curl cho từng endpoint ở đây nếu cần.
