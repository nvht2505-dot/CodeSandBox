# Đóng góp (Tóm tắt)

Xem chi tiết CONTRIBUTING.md trong repo — link: https://github.com/nvht2505-dot/CodeSandBox/blob/main/CONTRIBUTING.md

Tóm tắt nhanh:
- Fork → branch → PR vào `main`
- Dùng Conventional Commits
- Chạy `npm run lint` và `npm test` trước khi PR
- Mọi thay đổi logic cần kèm test

Vui lòng tôn trọng Code of Conduct.
